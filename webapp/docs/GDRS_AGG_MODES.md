# ГДРС: режимы агрегации «План» и «СКУД»

Экраны `/gdrs/people` и `/gdrs/equipment`, API `GET /api/gdrs-people` и `GET /api/gdrs-equipment`.
Режимы задаются независимо для плана и для факта СКУД.

## Режимы

| Подпись в UI | Ключ ядра | План | СКУД |
|---|---|---|---|
| Среднее за месяц | `month_avg` | среднее срезов 1С по периоду | сумма факта / число дней периода |
| N неделя | `week:N` | срез 1С на конец недели N | сумма факта недели / дни недели |
| За день | `day:YYYY-MM-DD` | срез 1С на выбранную дату | факт исходника ровно за эту дату |

«За день» — режим, а не значение: в `filters.agg_options` приходит подпись `За день`,
сама дата передаётся отдельным параметром.

## Параметры API

| Параметр | Значение |
|---|---|
| `plan_agg` / `skud_agg` | `Среднее за месяц` \| `N неделя` \| `За день` |
| `plan_day` / `skud_day` | дата в `YYYY-MM-DD` (или `ДД.ММ.ГГГГ`), нужна только при режиме `За день` |

Границы календаря отдаёт сам API: `filters.day_min`, `filters.day_max` (выбранный период)
и `filters.day_default` — последний день периода, где в исходнике есть факт.
День вне периода приводится к границе, в `meta.warning` попадает пояснение.
Выбранные дни возвращаются в `filters.selected.plan_day` / `skud_day` и в `meta.plan_day` /
`meta.skud_day`; подпись для шапки — `meta.agg_note` («План: 01.07.2026 · СКУД: 01.07.2026»).

## Поведение экрана в дневном режиме

- KPI, таблицы по проектам и контрагентам, распределение и матрица считаются за выбранный день.
- Недельные колонки матрицы (`show_week_columns`) выключаются, как и в режиме «N неделя».
- График динамики остаётся контекстом месяца, выбранный день подсвечен вертикальной меткой
  (видно при группировке «День»; для недель и месяцев подсветки нет).
- Нет строк исходника за дату (день после выгрузки `resursi`, будущий месяц) → СКУД 0
  и предупреждение «За ДД.ММ.ГГГГ нет факта СКУД в исходнике». План при этом остаётся:
  срез 1С существует и на будущие даты.

## Почему цифры за день не совпадают с сырым CSV

СКУД в отчёте — только контрагенты из справочника 1С_Kontr, с дедупом снапшотов `resursi`
и стоп-листом. Разрыв с суммой по колонке дня в CSV — то же поведение, что в режимах
«Среднее за месяц» и «N неделя», а не эффект дневной агрегации.

Тесты: `webapp/api/tests/test_gdrs_day_agg.py`.
