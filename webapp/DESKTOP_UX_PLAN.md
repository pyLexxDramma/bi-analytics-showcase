## Главные ограничения

1. **Цифры не меняются.** Все фазы — подача, навигация, состояние UI. Payload'ы
   API и расчёты в `services/*` не трогаем. Правка, меняющая значение в ячейке,
   в этот цикл не входит.
2. **Мобильная версия не деградирует.** Зеркально мобильному циклу: правка либо
   под `lg+`, либо общая с проверкой обоих вьюпортов. Принятые M1–M8 — эталон.
3. **Паритет с `[main]` остаётся ориентиром.** Десктоп принят как 1:1 со
   Streamlit (§0–§16 в `PARITY_ACCEPTANCE.md`). Всё, что меняет привычный вид
   (плотность, ширина, сортировка), включается опционально и по умолчанию
   повторяет текущее поведение.

## Цикл фазы

1. Правки в общих компонентах (одна фаза чинит сразу все дашборды).
2. Локально: `tsc --noEmit`, `npm run lint`, `npm run build`, перезапуск Next + API.
3. Пользователь смотрит локально на `:3000` — «ок» или список багов.
4. Commit/push по явной просьбе → GitHub Actions → стенд.
5. Приёмка на стенде → ✅ в этом файле, затем следующая фаза.

## Откат

Стенд разворачивается через `git reset --hard origin/main` в
`webapp/scripts/server_deploy.sh`, поэтому откат = вернуть `main` в нужное
состояние и передеплоить:

- одна фаза: `git revert <sha>` → push → Actions;
- весь цикл: `git revert --no-commit 7e921d7..HEAD` → один коммит → push;
- без нового коммита: `workflow_dispatch` на нужном SHA.

Данные (`webapp/data/`) правки UI не трогают, ingest и активная версия при
откате не меняются.

**Файлы.** `lib/use-url-filter-state.ts`, 11 вью с фильтрами,
`components/download-table-button.tsx`.

**Приёмка.** Меняю фильтр → адрес обновился без перезагрузки; F5 сохраняет срез;
ссылка в другом браузере открывает тот же срез; «Назад» не ломает экран.

## D2. Липкая шапка и первая колонка таблиц 🔄

**Проблема.** `position: sticky` в проекте нет вовсе. На длинных матрицах
(контрольные точки, ГДРС, БДДС) при прокрутке пропадает и шапка, и колонка
«Проект» — число теряет смысл.

**Что делать.**
- `thead th` — `sticky top-0` с непрозрачным фоном под обе темы; таблицы свёрстаны
  `border-separate`, что для sticky корректно.
- Первая колонка — `sticky left-0` там, где есть горизонтальный скролл.
- Учесть многоуровневые шапки (`rowSpan` в девелоперских проектах): липнет весь
  блок заголовка, а не одна строка.
- Довести `tabular-nums` до всех числовых колонок.

**Файлы.** `app/globals.css`, вью с матрицами.

**Приёмка.** Прокрутка длинной матрицы: шапка и «Проект» на месте, границы не
двоятся, тёмная тема без просветов, fullscreen (⛶) не сломан.

## D4. Сайдбар: сворачивание и прокрутка ⬜

**Проблема.** Панель жёстко `lg:w-[280px]` — на 1366 px это заметная доля ширины,
матрицы уходят в горизонтальный скролл. Плюс `lg:overflow-y-hidden
lg:hover:overflow-y-auto`: на невысоком экране низ меню недостижим, пока курсор
не внутри.

**Что делать.**
- Сворачивание до иконок, состояние в `localStorage`.
- Заменить hover-скролл на `overflow-y-auto` + `overscroll-contain`: колесо над
  дашбордом всё так же не двигает меню, но список доступен всегда.

**Файлы.** `components/app-sidebar.tsx`, `components/app-shell.tsx`, `globals.css`.

**Приёмка.** 1366×768 со всеми раскрытыми аккордеонами: виден блок «Версия
данных»; свёрнутый режим переживает перезагрузку; мобильный drawer без изменений.

## D5. Плотность и ширина полотна ⬜

**Проблема.** Контент ограничен `max-w-7xl` (1280 px): на 1920 по краям пусто, а
матрица внутри скроллится горизонтально.

**Что делать.**
- Переключатель «во всю ширину» (снимает `max-w-7xl`), состояние в `localStorage`.
- Режим плотности compact/comfortable — только вертикальные паддинги строк.
  По умолчанию — текущий вид (паритет с main).

**Файлы.** `components/app-shell.tsx`, `globals.css`.

**Приёмка.** На 1920 матрица помещается без горизонтального скролла; compact даёт
заметно больше строк; на 1366 ничего не ломается; мобильный вид не затронут.

## D6. Ощущение скорости ⬜

**Проблема.** Ленивая загрузка графиков включается только на мобиле
(`lazyOnMobile` в `plotly-figure.tsx`). Скелетон тоже мобильный
(`showSkeleton = showLoading && mobile`), десктоп получает блюр с оверлеем.

**Что делать.**
- `IntersectionObserver` и на `lg+`, с той же заглушкой по высоте layout.
- Скелетон таблицы/графика вместо блюра на десктопе.

**Файлы.** `components/plotly-figure.tsx`, `components/dashboard-loading.tsx`,
`components/app-shell.tsx`.

**Приёмка.** Первый экран тяжёлых отчётов открывается быстрее; при прокрутке
графики появляются без скачков layout; печать и fullscreen не ломаются.

## D8. Клавиатура и доступность ⬜

**Проблема.** `MultiSelectDropdown` закрывается по Esc, но не ходит стрелками и
не имеет «Выбрать все / Снять все» — на списке подрядчиков это ощутимо.

**Что делать.**
- Стрелки, Home/End, Enter в выпадающем списке; «Выбрать все / Снять все».
- Хоткеи: `/` — фокус в поиск, `Esc` — закрыть попап, `?` — шпаргалка.
- Проверить `focus-visible` на интерактивных элементах.

**Файлы.** `components/dashboard-filters.tsx`, `components/app-shell.tsx`.

**Приёмка.** Полный проход по фильтрам с клавиатуры без мыши; фокус виден;
скринридер читает состояние чекбоксов.
